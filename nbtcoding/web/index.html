BMW Coding

Read a module to see every setting with BMW's own names. To change one, pick a new value, press Review, then Write. Every read and every review saves a full backup you can restore. Keep the engine running or a charger on while writing. The head unit (HU_NBT) is never written: the Android Auto mod lives there.
